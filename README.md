# ragdoll

I was struggling to go through every data engineering and triathlon training book that exists in the wild as PDF files.
At the same time, I've always thought about RAG as a useless approach - mainly because I don't fully understand it (yet).

So in order to teach myself what RAG is and how and where to use it, I started ideating `ragdoll`.

`ragdoll` is supposed to be a platform for creating RAG pipelines: 
1. Create a project
2. Upload documents
3. Ask questions about them

Fully local: parsing, chunking, indexing, storage - everything runs on your machine.

This repository will serve as a learning tracker of sorts: it will propably contain glossaries of the concepts I learn in the process of reading stuff online, it will probably contain some ideas, pipe dreams or existential doubts.
It's a work in progress, but I hope it becomes something of use - if not, at least I've learned something in the process.

Highly inspired by Angela and Kezhan Shi's _[Enterprise Document Intelligence](https://towardsdatascience.com/document-intelligence-a-series-on-building-rag-brick-by-brick-from-minimal-to-corpus-scale/)_.
