# Starting point: no prior RAG build experience

Manuel has never built an embedding and retrieval pipeline. He knows what RAG means but has not
implemented one, not even a tutorial demo. He works in a healthcare software context and is a
practising engineer, so general software architecture, APIs and deployment are not the gap.

**Implications**: teach retrieval fundamentals from first principles, but do not teach general
software engineering. Skip "what is an API" style material entirely. The 2-4 hour weekly budget
means each session must produce one measurable artefact.
